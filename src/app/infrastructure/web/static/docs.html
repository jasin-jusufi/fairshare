🧭Basics

Everything belongs to a household. Members, expenses, settlements and chores live under /households/{household_id}/….

🪙
Money is always in cents. amount_cents: 9000 means CHF 90.00. There are no floating-point amounts. When splitting, leftover cents go to the participants with the largest fractional part, so the total always adds up exactly (ADR-004).

🚦Errors

Errors always have the same shape. The domain knows nothing about HTTP status codes; the mapping happens only at the API boundary.

StatusMeaningExample
400Business rule violatedPercentages do not add up to 100, payment exceeds the debt
404Resource does not existUnknown household or expense ID
409Conflicts with the current stateMember “Lea” already exists, week already planned
422Invalid request formatMissing required field, wrong data type
